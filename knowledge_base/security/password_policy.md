# Password and Authentication Policy

Northstar employees must protect corporate authentication credentials.

## Password requirements

Corporate passwords must meet the minimum length and complexity rules enforced by the Identity Portal. Employees must not reuse corporate passwords on personal services.

## MFA

Multi-factor authentication is required for remote access and sensitive internal services.

## Sharing

Passwords, recovery codes, and MFA approvals must never be shared with another person.

## Password changes

Employees who suspect credential compromise should change their password immediately and contact the Service Desk.

This policy defines security requirements. For the actual password reset procedure, employees should follow the Corporate Password Reset guide.
