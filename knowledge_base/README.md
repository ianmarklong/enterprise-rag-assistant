# Northstar Technologies Knowledge Base

This is a fictional enterprise knowledge base created for the Enterprise RAG Assistant project.

The documents intentionally contain:
- overlapping terminology;
- similar topics in different documents;
- cross-document dependencies;
- ambiguous user language;
- role and access distinctions;
- information that should not be inferred when it is absent.

These characteristics are deliberate so that retrieval quality, chunking, metadata, evaluation, and failure handling can be explored later.
