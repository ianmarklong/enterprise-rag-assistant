# Developer Workstation Setup

Developers receive the standard Northstar laptop build plus engineering tools.

## Required developer tools

Engineering workstations should include:
- Git;
- Python 3;
- a supported code editor;
- Docker Desktop on approved operating systems;
- the Northstar command-line utility;
- approved SSH tooling.

Some teams also require Node.js, Java, database clients, or cloud provider command-line tools.

## Docker Desktop

Docker Desktop provides a local development environment. Installing Docker Desktop does not grant access to the shared Northstar container management platform.

Access to shared development or production container environments is managed separately.

## Verification

New developers should confirm they can:
1. authenticate to Git repositories;
2. run Python locally;
3. build a sample container;
4. reach the engineering package registry.

Problems with the standard build should be reported to the Service Desk.
