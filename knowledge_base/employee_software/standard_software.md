# Standard Employee Software

All Northstar-managed laptops receive a baseline software package.

## Installed for all employees

The standard build includes:
- corporate endpoint protection;
- company VPN client;
- approved web browser;
- office productivity suite;
- video conferencing client;
- password manager;
- device management agent.

Employees should not reinstall baseline applications unless instructed by the Service Desk.

## Role-based software

Additional software depends on job function. Examples include:
- source-control tools for developers;
- database clients for data teams;
- design tools for product teams;
- remote administration utilities for IT staff.

Requests for non-standard software must be submitted through the Software Request Portal.

## Unapproved applications

Employees must not install unlicensed software or applications that bypass Northstar security controls.
