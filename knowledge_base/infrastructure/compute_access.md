# Shared Compute Access

Northstar provides shared CPU and GPU compute environments for engineering teams.

## Access request

Access is requested through the Access Management Portal. The request should identify:
- the compute environment;
- the project or team;
- whether CPU or GPU resources are required;
- expected workload duration.

Manager approval is required for standard development compute.

## Production systems

Access to production compute is managed separately from development compute. Production administrative access requires system-owner approval and may require an elevated privileged session.

## Remote access

Shared compute environments are reachable only from approved corporate networks or through the company VPN.

## Credentials

Employees authenticate using corporate identity where supported. SSH keys may also be required for specific engineering systems.
